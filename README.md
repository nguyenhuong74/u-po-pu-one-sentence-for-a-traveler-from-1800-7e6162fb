One sentence, at most 200 characters, that explains the modern internet to a time traveler arriving from the year 1800 — built only from things they already know: roads, post offices, printing presses, libraries, letters, and books.

> It is a road that joins every post office, printing press and library on earth, so a letter you write arrives in a breath and a book on any shelf can be opened from your own chair.

The sentence uses no word coined after 1800: no internet, computer, screen, website, email, phone, or digital. The single image — one road joining every post office, printing press, and library on earth — carries the whole explanation: letters that arrive in a breath, and any book opened from your own chair.

## Run it

```sh
node main.ts
```

This validates the sentence (one sentence, 1–200 characters, exactly one period at the end, no modern words) and writes it to `entry.txt` in `/output`, or in `$MAKEFUN_OUTPUT_DIR` when set.
